# 科室工作推进登记

一个用于记录科室管理者日常工作开展与推进情况的本地工具，年底可直接生成给领导的年度总结。

## 在线使用

- GitHub Pages：https://alex-chan116.github.io/keshi-work-tracker/
- 手机、电脑均可直接打开，无需连接同一 Wi-Fi。

## 使用

- 直接打开 `index.html` 即可使用。
- 也可以在电脑上运行 `python3 -m http.server 4173 --bind 0.0.0.0`，然后访问 `http://127.0.0.1:4173/`。
- 手机与电脑连接同一 Wi-Fi 时，手机浏览器打开 `http://电脑局域网IP:4173/` 即可使用。

## 数据说明

在线使用时，数据保存在当前设备的浏览器本地。电脑和手机的数据相互独立，换设备后可在“数据 → 导入数据”中恢复备份。

## 记录内容

- 开展日期、事项内容、负责人
- 工作目标与当前推进状态
- 推进时间点：每次日期、状态、情况说明
- 最终目标达成情况与结果说明

## 年终总结

- 点击“年度总结”自动生成年度汇总、月度推进表、事项明细。
- 支持复制总结、打印/导出 PDF、导出 Markdown。

## 数据

- 数据保存在当前浏览器的本地存储中。
- 建议定期通过“数据 → 导出数据备份”保存 JSON 备份。
- 换电脑或手机时，用“数据 → 导入数据”恢复备份。
